# FINCA VOC 리포트 제작

기준 산출물: 26상반기_FINCA_VOC_리포트.pptx / 26상반기_FINCA_VOC_근거자료.xlsx.
첨부에 `FINCA_VOC리포트_분석코드.zip`이 있으면 반드시 풀어서 그 코드(prod.py → build.py → analysis.py → export.py → deck.js, make_xlsx.py)를 재사용하고, 기간·파일 경로·curated.js만 새로 작성한다. 이전 리포트 PPT가 첨부되면 구성·디자인을 그대로 따른다.

## 0. 시작 전 확인 (사용자에게 질문)
- 분석 기간, 리포트 단위(분기/반기), 비교 기준(직전 분기 / 전년 동기)
- 기간 중 운영 이슈(출고지연 등)와 관련 파일 유무
- 추가 채널(W컨셉·EQL 등) 여부

## 1. 데이터 확인
파일별 행 수·기간·주요 컬럼을 표로 보여주고 누락을 먼저 알린다. 필요 데이터:
- 리뷰: 29CM(item_name, point, contents, insert_timestamp, order_serial) / 아임웹(상품명, 리뷰별점, 리뷰본문, 리뷰작성일, 주문번호) / 무신사(상품명, 평점, 후기 내용, 등록일시)
- 문의: 29CM 게시판(상품, 문의 내용, 등록일시) / 자사몰(상품명, 제목, 내용, 작성시각 — 직원 답변글 제외) / 무신사(상품명, 제목, 문의내용, 작성일)
- 반품·교환: 29CM(주문번호+사유, 상품명 없음) / 자사몰(주문번호·상품명·옵션·반품사유·상세사유·주문일·수량) / 무신사(클레임상태·사유·상세사유·요청일시·수량)
- 29CM 주문상품 내역: 브랜드 핀카 + 핀카_대형러그 모두 포함 (반품률 분모, 29CM 반품은 주문번호로 연결하거나 주문상태 '반품' 필터로 상품별 집계)
- 상품리스트(오클릭): 품번, 품명, 브랜드, 복종, 성별, 추가분류, 년도, 시즌
원본 엑셀은 채널마다 시트·헤더가 다르므로 확인 후 변환한다.

## 2. 분석 규칙
- 범위: FINCA만(HaTA·테스트·사은품 제외). 반품률·교환률 = 29CM 반품(교환) 라인 ÷ 취소 제외 판매 라인.
- 상품 매칭: 상품명 키워드로 세부코드 판정 → 같은 코드 안에서 품명 유사도(rapidfuzz token_set_ratio), 60 미만 공란. 대표 상품의 추가분류가 비면 같은 라인으로 보완하고 '라인 보완' 표시. 컬러별로 쪼개진 대형러그 등은 라인 단위로 묶는다.
- MD 그룹: HM → 베딩/러그/충전재/바스/홈데코, WR·SW → 웨어, AC → 잡화, KC → 키친(콜라보는 아이템 기준).
- 리뷰 불만 문장: 1~2점 전체 / 3점 아쉬움 표현 문장(없으면 전체) / 4~5점은 '아쉽·별로·불편·실망·좀/너무+형용사' 등 명확한 불만 문장만, 안심 표현(괜찮·만족·좋아요)만 있으면 제외.
- 부정의 부정 제거(문장 단위, 리뷰 전체를 빼지 않음): '불편하지 않아요', '보풀은 없어요', '올풀림 그런 것도 없고', '전혀 안 작아요', '(너무) 얇지도 두껍지도 않아요', '마감도 좋아요'.
- 오인식 방지: '하자마자·하자면·하자고' ≠ 하자, '세탁하니' ≠ 탁하다(색상).
- 상품 불만 유형: 색상/실물차이, 사이즈/핏, 소재/촉감, 두께/보온감, 구김, 세탁/내구성, 봉제/마감불량, 오염/냄새/검수, 기능/사용성. 운영: 배송/출고, 포장, 가격/가성비, CS응대.
- 문의 유형(1개, 우선순위): 불량/하자 > 오배송/누락 > 교환/반품/환불 > 배송/출고지연 > 재입고/품절 > 주문변경/취소 > 상품정보/사이즈 > 기타.
- 반품·교환 사유: 단순변심 / 사이즈·색상 / 상품불량·파손 / 오배송·누락 / 상품불만족·정보상이 / 배송지연·품절.
- 불량 VOC: 리뷰(세탁/내구성·봉제/마감·오염/검수) + 반품·교환 상품불량/파손 + 문의 불량/하자.
- 키워드(표현 사전): 긍정 = 4~5점 리뷰 언급 수(예뻐요, 디자인·패턴, 색감, 귀여워요, 선물용, 인테리어 포인트, 부드러워요, 편해요, 재구매, 시원해요 등), 부정 = 불만 문장 언급 수(커요, 작아요, 얇아요, 허리 밴딩, 실물 색감 차이, 올풀림·실밥, 구멍·뜯어짐, 마감 아쉬움, 흠집, 깨짐, 배송 지연 등). 둘 다 부정의 부정 제거 후 집계.
- 추가분류 판단: 앵커(브랜드 대표) = 우선 개선, 캐리오버 = 재생산 전 개선, 레귤러 = 표준 운영. 표시용 태그가 아니라 개선안 문구에 반영.

## 3. PPT 구성 (LAYOUT_WIDE, 맑은 고딕)
표지 → 분석 기준 → 핵심 메시지 1장(기간을 관통하는 한 문장 + 근거 숫자 3개, 후보 3개를 먼저 제안) → VOC 종합 → 카테고리 매트릭스 → 월별 흐름 → 카테고리별 [요약 → ① 판매 상위 상품 VOC → ② 불량·하자 대표 VOC] → (기간 중 운영 이슈가 있으면 이슈 섹션: 간지 + 개요 + VOC 영향) → Action Plan(개선 과제) → FINCA 전체 키워드(긍정·부정 TOP15) → 부록(분류 기준·데이터 한계).
- 요약: 세부카테고리 지표표, MD 체크포인트, 키워드 TOP8(긍정/부정), 반품·교환 사유 차트.
- ① 판매 상위: 29CM 판매라인 순, 이미지 없음, 카드 6개/장(큰 카테고리는 12개). 카드 = 판매·반품률·교환 / 리뷰·평점·불량 클레임·문의 / 주요 불만(재입고·배송지연 문의 10건 이상이면 포함) / 좋았던 점(4~5점 키워드) / ★평점 인용 2~3개 / 개선안.
- ② 불량·하자: 카드 2개/장, 2.5인치 이미지 칸(CS 접수·리뷰 사진), 불량 VOC 지표, 대표 VOC + 같은 유형 VOC, 확인 포인트. 카테고리당 2~3장, 불량 VOC가 적으면 1장.

## 4. 대표 VOC 선정 기준 (중요)
- '어디가 어떻게 불량인지' 구체적으로 적힌 원문만 대표로 쓴다.
- 대표 금지: 교환·CS 처리 지연 이야기가 중심인 문장, '불량이었는데 빠르게 교환해주셔서 감사' 같은 칭찬, 불량 여부만 묻는 질문, 옵션명만 있는 반품 건, 다른 브랜드 경험담, 택배 회수 등 물류 문의.
- 컬러별로 흩어진 상품을 합쳐 보고, 판매량이 적어도 착용 직후 봉제선 터짐 같은 심각한 불량은 포함.
- 29CM 반품·교환은 상세 사유가 없으므로 건수만 제시하고 'CS 사진으로 부위 확인'을 확인 포인트에 적는다.
- 인용 시 이름·전화번호·주소·주문번호 삭제, 생략은 '…', 원문 맞춤법은 고치지 않는다.

## 5. 엑셀 시트
안내 / 카테고리요약 / 세부카테고리 / 상품별VOC(추가분류·년도·시즌·분류근거·불량 리뷰/문의·재입고/배송지연 문의·좋았던 점) / 월별추이 / 키워드 / 불량VOC원문(이미지 확보 O/X·MD 확인 메모 칸) / 리뷰원문 / 문의원문 / 반품교환원문 / 상품매칭표. 비율은 엑셀 수식으로 넣는다.

## 6. 마무리 검수
1. PPT를 PDF→이미지로 렌더링해 글자 넘침·겹침을 확인하고 고친다.
2. curated 문구 속 숫자를 집계 데이터와 스크립트로 대조한다.
3. 불만 유형별 20건 샘플을 뽑아 오분류(긍정 문장, 다른 상품 리뷰 혼입)를 확인하고 비율을 보고한다.
4. 대표 VOC가 4번 기준에 맞는지 카드별로 다시 확인한다.
5. 새로 추가한 규칙(제외 표현·라인 통합·추가분류 보완·슬라이드 순서)은 코드에 반영하고, 갱신된 분석코드 zip을 함께 전달한다.
