# FINCA·HaTA CX 대시보드

VOC · 리뷰 · 게시판 · CS 데일리를 한곳에서 관리하고 주간·월간 보고를 자동으로 만드는 사내 대시보드입니다.

- **접속 주소**: https://finca-hata-cx.netlify.app
- **로그인**: 공용 직원 계정 (Supabase Authentication에서 관리, 외부 가입은 막혀 있음)

## 알아두면 좋은 기준

- **데이터는 전일 기준**: 보고일 9/22 = 9/21 데이터. 월요일 보고일에는 금~일 3일치를 합쳐서 입력합니다.
- **한 주 = 월~일** (데이터 날짜 기준). 매월 첫 화요일 보고일이 그달 1주차 시작입니다. 예) 9월 1주차 = 8/31~9/6.
- **과실(브랜드 과실)**: VOC 구분이 품질 · 세탁·이염 · 내구성인 건.
- **부정 리뷰**: 1~3점 (리뷰 분석 화면에서 2점 이하로 바꿔 볼 수 있음).
- **업로드는 중복 걱정 없음**: 같은 파일·같은 기간을 다시 올려도 이미 있는 건 건너뜁니다.
- **화면 속도**: 리뷰·게시판 분석은 기본 최근 6개월만 불러오고, '전체'를 누르면 전부 불러옵니다.

## 지원하는 업로드 파일

| 종류 | 형식 |
|---|---|
| 리뷰 | 29CM(원본·파트너 화면) · 아임웹 · 무신사 · 기존 시트 '리뷰 low' (엑셀/CSV) |
| 게시판 | 29CM · 무신사(2가지) · 아임웹 · 카페24 |

처음 보는 형식은 "형식을 알 수 없어 건너뜀"으로 표시됩니다. 새 형식은 `src/upload.jsx`(리뷰·게시판)와 `src/orders.jsx`(주문)의 형식 목록에 추가합니다.

## 관리자용 정보

### 구성
- **화면**: `index.html` + `app.css` + `src/*.jsx` (React + 브라우저 Babel, 빌드 없음)
- **데이터**: Supabase 프로젝트 `hbudvjnqzejqbvkqfklz` (finca-hata-voc-dashboard-v2). 모든 테이블은 로그인한 직원만 읽기·쓰기 가능(RLS)
- **배포**: GitHub `main`에 올리면 Netlify가 1분 안에 자동 반영

### src 파일
| 파일 | 내용 |
|---|---|
| `lib.jsx` | DB 연결, 공통 부품, 기준 코드, 날짜 도구 |
| `app.jsx` | 로그인 · 메뉴 · 화면 전환 |
| `home.jsx` | 메인 요약 |
| `reports.jsx` | 보고서 (주간 리뷰 · 월간 리뷰) |
| `daily.jsx` | CS 데일리 입력, 주차 계산, 보고서용 표 |
| `insights.jsx` | VOC 현황 (후속 조치 보드는 숨김 상태) |
| `voc.jsx` | VOC 접수 · 목록 |
| `upload.jsx` | 파일 읽기 · 형식 인식 · 업로드 공통 |
| `reviews.jsx` | 리뷰 업로드 · 분석, 부정 리뷰 → VOC |
| `board.jsx` | 게시판 업로드 · 분석, 상품 자동 연결 |
| `orders.jsx` | 주문 업로드, 대분류 자동 분류 |
| `settings.jsx` | 기준 관리 · CX 응대 주의사항 |
| `manuals.jsx` | 업무 매뉴얼 |

### DB 설정 (SQL)
`supabase/` 폴더의 SQL을 번호 순서대로 Supabase SQL Editor에서 실행합니다. 새 DB를 만들 때만 필요하며, 현재 DB에는 01~06이 모두 적용되어 있습니다.

| 파일 | 내용 |
|---|---|
| `01_phase1_schema.sql` | 기준 코드, VOC, CX 주의사항, 사진 저장소, 보안 |
| `02_cs_daily_schema.sql` | CS 데일리, 월간 메모 |
| `03_reviews_board_schema.sql` | 리뷰, 게시판 |
| `04_manuals_schema.sql` | 업무 매뉴얼, 첨부 저장소 |
| `05_voc_form_update.sql` | VOC 구분·문의 채널 개편, 처리 구분·담당 부서·완료일 |
| `06_orders_schema.sql` | 주문 |

### 숨겨 둔 기능
